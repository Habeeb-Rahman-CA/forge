Data Path Summary: The Forge-16 employs a unified synchronous architecture where instructions and data share a 64 KB flat address space. The Control Unit fetches 32-bit instructions (two 16-bit words) from PC, decodes the 6-bit opcode, routes operands from R0–R7 to the ALU, executes the operation, and optionally engages the 16-bit Memory Bus for LOAD/STORE or the I/O bus for system calls.
